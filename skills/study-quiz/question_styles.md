# Question styles

Rotate through these so the quiz doesn't get repetitive.

- **Define:** "What does UCB stand for, and what does it add to action selection?"
- **Compare:** "How does a constant step size differ from sample averaging?"
- **Apply:** "Your reward probabilities drift over time. Which method should you
  use, and why?"
- **Spot the error:** state something that is almost right and ask the user to
  find the mistake.

Avoid questions with a one-word answer, except as a warm-up.
